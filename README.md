# SauceDemo Playwright Framework (Python)

Python Playwright test framework built on `pytest` + `pytest-playwright`, with page
objects, custom fixtures, environment configuration, and HTML reporting.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chrome
cp .env.example .env
```

Update `.env` with the credentials for the SauceDemo environment under test. The public
demo accepts `standard_user` / `secret_sauce`, and lists other available users on the
login page.

## Run tests

```bash
pytest                   # Headless tests (opens report.html when done)
pytest --headed          # Run with a visible browser
pytest -m smoke          # Run tests tagged @pytest.mark.smoke
pytest -n auto           # Run tests in parallel
pytest --reruns 2        # Retry failing tests
pytest --tracing on      # Record a trace for every test
```

Open the latest HTML report:

```bash
open report.html
```

Override the target environment without changing files:

```bash
BASE_URL=https://www.saucedemo.com pytest
```

## Structure

```text
conftest.py            # Fixtures (timeouts, base_url) + post-test screenshots
pytest.ini             # pytest configuration (browser, timeouts, reporting, markers)
tests/
  positive/            # Successful workflow tests
  negative/            # Validation and failure-path tests
screenshots/           # Screenshots captured after each test
report.html            # HTML report generated by pytest-html
requirements.txt
```

## Configuration notes

- `pytest.ini` defaults mirror the original framework: `--browser chromium
  --browser-channel chrome` drives the installed Google Chrome.
- `pytest-playwright` supports `--tracing on|off|retain-on-failure`, so
  `retain-on-failure` is used instead of an "on-first-retry" equivalent.
- Parallel execution uses `pytest-xdist` (`-n auto`); CI retries use
  `pytest-rerunfailures` (`--reruns 2`).
- Video is disabled by default because Playwright's bundled ffmpeg is unavailable on
  macOS 12. On macOS 13+ / CI run `playwright install ffmpeg` and add
  `--video retain-on-failure` to `addopts` to enable it.
